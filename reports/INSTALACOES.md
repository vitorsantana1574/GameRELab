# Instalações

O laboratório usa pacotes portáteis por versão. O [manifesto](../manifests/tools.windows.json) contém 22 entradas e o [guia](../docs/FERRAMENTAS.md) descreve seus usos. JDK 21 e Gradle são usados no projeto Minecraft. JDK 25 é a dependência do Ghidra 12.2. Node 24 portátil atende ferramentas com requisito de uma revisão mais nova que a instalação global.

Consulte [Testes](TESTES.md) para o que foi executado. O Toolkit de Baldur’s Gate 3 é distribuído separadamente pela Steam.
