# Baldur’s Gate 3

O fluxo oficial de mods usa o **Baldur’s Gate 3 Toolkit** na biblioteca da Steam e o **BG3 Toolkit Data** nas DLCs do jogo. O editor e os dados são gratuitos para proprietários do jogo. [Guia da Larian](https://docs.baldursgate3.game/Getting_Started%3A_Installing_the_Toolkit)

O teste inicial é criar um projeto vazio, carregar os dados do jogo, gravar uma alteração pequena em um recurso do projeto e conferir se o editor consegue empacotá-lo. Use `projects/baldurs-gate-3/local/` para exportações de trabalho e anote no projeto os UUIDs próprios e a versão de jogo em que foram testados.
