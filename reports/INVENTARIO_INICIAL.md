# Inventário resumido

Ferramentas de desenvolvimento reaproveitadas incluem Git, Python 3.12, .NET 10, Claude Code, Codex e VS Code. O perfil de desenvolvimento de Minecraft usa a mesma versão do jogo e loader que a instalação existente de Cobblemon.

Esta versão do relatório descreve dependências do projeto. Inventários com caminhos, perfis de usuário ou detalhes do computador ficam em `reports/local/`.
