# Situação da implantação

O projeto está estruturado com ferramentas portáteis para Windows, um mod de exemplo Fabric, uma consulta ao Data Dragon e uma amostra original de código para análise estática. O servidor MCP do projeto expõe guias e fontes para consulta.

Consulte os [testes executados](TESTES.md) e os [detalhes de instalação](INSTALACOES.md). A utilização dentro dos jogos é uma etapa separada da validação da instalação e da compilação.
